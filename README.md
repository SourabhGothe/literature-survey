## Agent memory

[`agent-memory/baseline-selection-research.md`](agent-memory/baseline-selection-research.md)
reviews open-source long-term memory systems for LLM agents (Hindsight,
LightMem, EverMemOS/EverOS, Mastra Observational Memory, MemOS, HippoRAG 2,
A-Mem, SimpleMem, MemoryOS, Mem0, and others). It looks at the main
benchmarks (LongMemEval, LoCoMo, BEAM, MemoryAgentBench, PersonaMem) and at
what independent, controlled evaluations show. It ends with a recommended
choice of baselines and an evaluation protocol.
